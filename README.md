## 🎯 เกี่ยวกับโปรเจกต์

ระบบช่วยตัดสินใจสำหรับสหกรณ์แปรรูปยางแผ่นรมควัน ที่ช่วยวิเคราะห์และแนะนำว่าควร:
- **ผลิตแผ่นยาง** จากน้ำยางสดทันที
- **เก็บน้ำยางสด** ไว้ผลิตในวันถัดไป
- **ขายน้ำยางสดทิ้ง** เมื่อไม่คุ้มค่าในการผลิต

โดยคำนึงถึง:
- 📦 **กำลังการผลิต** (60,000 กก./วัน)
- 🏪 **ความจุ Stock** (20,000 กก.)
- 💰 **ราคาน้ำยางสด** และ **ราคาแผ่นยางในอนาคต**
- 💸 **ต้นทุนการผลิต** และ **ค่าเก็บรักษา**

---

## ✨ คุณสมบัติหลัก

### 1. 📊 วิเคราะห์การตัดสินใจแบบเรียลไทม์
- คำนวณปริมาณที่ควรผลิต/เก็บ/ขายทิ้ง
- แสดงเหตุผลการตัดสินใจอย่างชัดเจน
- อัปเดต Stock คงเหลือทันที

### 2. 💰 เปรียบเทียบทางเลือก
- เปรียบเทียบ **เก็บไว้ผลิต** vs **ขายสดทันที**
- แสดงรายได้สุทธิแต่ละทางเลือก
- แนะนำทางเลือกที่คุ้มค่าที่สุด

### 3. 📈 วิเคราะห์ทางการเงิน
- รายได้จากการผลิตแผ่นยาง
- รายได้จากการขายน้ำยางสด
- รายได้สุทธิรวมทั้งหมด

### 4. 🎨 UI ที่ใช้งานง่าย
- ออกแบบด้วย Streamlit
- กรอกข้อมูลง่าย รวดเร็ว
- แสดงผลเป็นกราฟและตาราง

## 🚀 การติดตั้ง

### ขั้นตอนที่ 1: Clone โปรเจกต์
```bash
git clone https://github.com/yourusername/Latex-Management-02.git
cd Latex-Management-02
```

### ขั้นตอนที่ 2: สร้าง Virtual Environment

**Windows (PowerShell):**
```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

**macOS/Linux:**
```bash
python3 -m venv .venv
source .venv/bin/activate
```

### ขั้นตอนที่ 3: ติดตั้ง Dependencies
```bash
pip install -r requirments.txt
```

### ขั้นตอนที่ 4: รันแอปพลิเคชัน
```bash
streamlit run streamlit_app.py
```

เว็บแอปจะเปิดที่: `http://localhost:8502`

## 📖 การใช้งาน

### 1. ตั้งค่าพารามิเตอร์โรงงาน
- กำลังการผลิต (กก./วัน)
- Stock สูงสุด (กก.)
- ต้นทุนการผลิต (บาท/กก.)
- ระยะเวลาผลิต (วัน)

### 2. กรอกข้อมูลประจำวัน
- **น้ำยางสดที่เข้ามาวันนี้** (กก.)
- **น้ำยางใน Stock ปัจจุบัน** (กก.)
- **ราคาน้ำยางสดวันนี้** (บาท/กก.)

### 3. กรอกราคาแผ่นยางในอนาคต (บังคับ)
- ✅ เช็ค "ทราบราคาแผ่นยางรมควันในอนาคต"
- **ราคาแผ่นยางวันที่ +4** (บาท/กก.)
- **ราคาแผ่นยางวันที่ +5** (บาท/กก.)

### 4. กดปุ่มวิเคราะห์
- ระบบจะแสดงผลการวิเคราะห์
- แนะนำการตัดสินใจ
- แสดงการเปรียบเทียบทางเลือก

## 🔧 การปรับแต่ง

### เปลี่ยนค่าคงที่ในโรงงาน
แก้ไขในไฟล์ `utils/daily_decision.py`:

```python
class LatexDecisionEngine:
    def __init__(self):
        self.PRODUCTION_CAPACITY = 60000  # กก./วัน
        self.MAX_STOCK = 20000           # กก.
        self.PRODUCTION_COST = 5         # บาท/กก.
        self.PRODUCTION_DAYS = 4         # วัน
        self.STORAGE_COST_DAY1 = 0.28   # บาท/กก.
        self.STORAGE_COST_DAY2_10 = 0.14 # บาท/กก./วัน
        self.TRANSPORT_COST_PER_20K = 17000  # บาท
```

หรือปรับผ่าน UI ในส่วน **"ตั้งค่าพารามิเตอร์โรงงาน"**

## ❓ คำถามที่พบบ่อย (FAQ)

### Q1: ทำไมต้องกรอกราคาแผ่นยางในอนาคต?
**A:** เพราะระบบต้องเปรียบเทียบว่าคุ้มค่าเก็บไว้ผลิตหรือขายทิ้งทันที

### Q2: Stock เดิมจะถูกใช้อย่างไร?
**A:** ระบบใช้ Stock เดิมผลิตก่อนเสมอ (FIFO) เพื่อไม่ให้เน่าเสีย
